# 3.3.2 贝叶斯预测分布

## 学习目标

从参数后验边缘化得到测试点的预测均值与方差，并区别“潜在回归函数的不确定性”和“含噪声观测的不确定性”。

## 推导

沿用 `3.3.1` 的线性模型，给定新输入 \(x_*\) 的特征 \(\boldsymbol\phi_*\in\mathbb R^{D+1}\)，已知

\[
\mathbf w\mid\mathcal D\sim\mathcal N(\mathbf m_N,S_N),\qquad
t_*\mid\mathbf w,x_*\sim\mathcal N(\boldsymbol\phi_*^\top\mathbf w,\beta^{-1}).
\]

将参数 \(\mathbf w\) 积分掉：

\[
p(t_*\mid x_*,\mathcal D)
=\int p(t_*\mid x_*,\mathbf w)\,p(\mathbf w\mid\mathcal D)\,\mathrm d\mathbf w.
\]

利用高斯线性变换及独立噪声求和：

\[
\mathbb E[t_*\mid\mathcal D]=\boldsymbol\phi_*^\top\mathbf m_N,
\qquad
\operatorname{Var}(t_*\mid\mathcal D)=
\underbrace{\boldsymbol\phi_*^\top S_N\boldsymbol\phi_*}_{\text{参数不确定性}}
+\underbrace{\beta^{-1}}_{\text{不可约观测噪声}}.
\]

所以返回的 `variance` 是**观测预测方差**；如果预测无噪声潜在函数，必须去掉 \(\beta^{-1}\) 项。可信区间需要正确的模型假设与后验解释，不能把经验测试误差等同于后验标准差。

## 计算与测试

1. 从全方差公式 \(\operatorname{Var}(t)=\mathbb E[\operatorname{Var}(t\mid w)]+\operatorname{Var}(\mathbb E[t\mid w])\) 独立推导本节方差。
2. 在训练区间外选取远离数据的新输入，讨论多项式特征下不确定性可能如何变化。
