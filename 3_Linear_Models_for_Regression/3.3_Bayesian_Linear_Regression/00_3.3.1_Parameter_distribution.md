# 3.3.1 贝叶斯线性回归：参数后验分布

## 学习目标

将先验精度、噪声精度与后验精度严格区分；通过完成平方推导高斯后验；将矩阵公式与 Cholesky 求解对应起来。

## 模型与推导

记 \(\Phi=[\mathbf 1,X]\in\mathbb R^{N\times(D+1)}\)，\(\mathbf t\in\mathbb R^N\)。假设

\[
\mathbf w\sim\mathcal N(\mathbf0,\alpha^{-1}I),\quad
\mathbf t\mid\mathbf w,X\sim\mathcal N(\Phi\mathbf w,\beta^{-1}I).
\]

这里 \(\alpha>0\) 是**先验精度**，不是先验方差；\(\beta>0\) 是观测噪声精度。**截距也服从该零均值高斯先验**；这与第 1.2.5 节不惩罚截距的 MAP 示例不同。

忽略与 \(\mathbf w\) 无关的常数：

\[
\log p(\mathbf w\mid X,\mathbf t)
=-\tfrac12\big[\alpha\mathbf w^\top\mathbf w+
\beta(\mathbf t-\Phi\mathbf w)^\top(\mathbf t-\Phi\mathbf w)\big]+c.
\]

展开二次项，收集

\[
A=\alpha I+\beta\Phi^\top\Phi,\qquad
\mathbf b=\beta\Phi^\top\mathbf t,
\]

则指数中的二次形式等于 \(-\tfrac12(\mathbf w-A^{-1}\mathbf b)^\top A(\mathbf w-A^{-1}\mathbf b)+c'\)。因此

\[
p(\mathbf w\mid X,\mathbf t)=\mathcal N(\mathbf m_N,S_N),\quad
S_N=A^{-1},\quad \mathbf m_N=S_N\mathbf b.
\]

\(\alpha>0\) 保证 \(A\) 正定，即使 \(\Phi\) 不满列秩也有规范化的后验。

## 实现与验证

`BayesianLinearRegression` 的 [源码](../../prml/supervised.py) 使用 Cholesky 三角求解得到 \(\mathbf m_N\) 与 \(S_N\)，而不是实际调用显式逆函数。测试用小维度矩阵的独立解析结果核验均值与协方差。

运行：`python "3_Linear_Models_for_Regression/3.3_Bayesian_Linear_Regression/00_3.3.1_Parameter_distribution.py"`。
